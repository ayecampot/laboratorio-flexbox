Dos herramientas que trabajan juntas

Box Model

Todo elemento HTML ocupa una caja. CSS permite controlar su contenido, espacio interno (padding), borde (border) y espacio exterior (margin).

Flexbox

Es un sistema para distribuir y alinear los hijos directos de un contenedor. Se activa en el padre con display: flex.

¿Cuál uso?

Para dar espacio interno a una caja, Box Model. Para ubicar tres elementos uno al lado del otro, Flexbox. Se pueden combinar.

01 · Espacios

Box Model: qué ocupa una caja

Content es el contenido; padding separa el contenido del borde; border delimita la caja; margin separa la caja de otros elementos.

03 · Direcciones
Flexbox: eje principal y eje cruzado
Al activar display: flex, la dirección inicial es row. El eje principal sigue la dirección; el eje cruzado es perpendicular. No memorices «justify es horizontal»: depende de la dirección.

06 · Propiedades de los hijos
Flex-grow, flex-shrink y flex-basis
Las tres propiedades se aplican a los hijos flexibles, no al contenedor. En este ejemplo, a cada .item.
flex-basis
Establece el tamaño base sobre el eje principal, antes de distribuir espacio. En row, es una referencia de ancho.
flex-grow
Indica qué proporción del espacio sobrante puede recibir un hijo. No significa «el doble de ancho total».
flex-shrink
Indica cómo puede reducirse un hijo si no alcanza el espacio. Con 0 se impide esa reducción por Flexbox.
Se mantiene flex-wrap: nowrap para que se note especialmente flex-shrink.
